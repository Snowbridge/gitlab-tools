## 2.3.4

Добавлена возможность полноценно использовать регэкспы в ключе поиска `--query-path`.

Проблема была в том, что для shell ряд символом являются управляющими, соответственно, в "сыром" виде эти смволы использовать в аргументах командной строки нельзя.
Для избегания конфликтов с управляющими символами оболочки, в регэкспах нужно заменять служебные символы:

| Управляющий символ | Замена |
|--------------------|--------|
| !                  | ¡      |
| -                  | ⊸      |
| -                  | ⌁      |
| (                  | ⟮      |
| )                  | ⟯      |
| ;                  | ⁏      |
| $                  | ฿      |

То есть, чтобы склонить всё из группы `myapp`, но без подгруппы `myapp/legacy`: \
`$ gitlab-tools clone --dir . --qp ^myapp\/⟮?¡legacy⟯.*` 

Здесь восклицательный знак и скобки в регэкспе заменены безопасные подмены.
