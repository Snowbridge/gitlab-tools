# Gitlab Tools

## 🪦 Развитие прекращено

Эта утилита — ранний предшественник
[Git Herder](https://github.com/git-herder/git-herder) (`githerd`).
Развитие прекращено: новых возможностей не будет, в эксплуатацию её
брать не нужно, а на свежих версиях node она собирается со скрипом
и матами, лечить это никто уже не будет.

Пользуйтесь `githerd`, а не этой утилитой. Git Herder закрывает те же
задачи — массовые операции над репозиториями и локальными рабочими
копиями — умеет больше, делает это лучше и будет развиваться дальше.

Установка и команды:
[github.com/git-herder/git-herder](https://github.com/git-herder/git-herder).
